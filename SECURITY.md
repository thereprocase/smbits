# Security

Report a vulnerability privately through **Security → Report a vulnerability** on this repository. Include the SMBits version, Android version, and steps or a test share setup that reproduces it.

The app's security design, including SMB policy, credential storage, transfer staging and verification, is described in [docs/security.md](docs/security.md). Dependency versions and their audit are in [docs/dependencies.md](docs/dependencies.md).
